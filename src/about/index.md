# About the site and more about me

## The site

**TL;DR :** This site uses 11ty to compile Handlebars and Markdown files into HTML. I use TailwindCSS and DaisyUI because they are easy to understand and easy to use.

### Why 11ty?

I've been a web developer for a long time, but it's been 11 years since I've done anything that did not use a frontend stack made by others much smarter than myself. I wanted my personal website to be as basic as possible.

Now, technically, I could have went with the vanilla web development stack and use HTML, CSS and JS. There is no reason that this would not have worked. However, I'm currently trying to go deeper into the architecture of frontend frameworks and I lacked a lot of knowledge when it came to the build process. This made me look into using a library that would atleast require me to run a build step.

I chose 11ty simply because it gave me the option to use as little of it as possible. This meant that I did not have to use anything I did not understand. 11ty came with the added bonus of having the features that were very helpful for a blog, even if I did not realize it at the time of choosing.

### Why TailwindCSS and DaisyUI?

Like a lot of people, the first time I saw TaiwindCSS, I hated it. The amount of class names to achieve something that I could easily write in a custom css file was crazy! But then another dev suggested we use it for a project at work and I believe in atleast trying things I hate before writing them off. Lo and behold, the guys at TailwindCSS were on to something and my brain just so happened to align with whatever they possesed them to release it into the world. The only thing that I missed coming from the Bulma CSS Framework were all the components. I found DaisyUI filled that gap perfectly and here we are!

I do plan on going deeper into designing my own components and such, but at the moment I'm UIX is at the bottom of the list of things I "have" to learn. I do enjoy all the DaisyUI examples of components that do not rely on JS though. One example that I find very cool is the use of the details and summary semantic html tags for the accordion component.
